# افزودن دادهٔ حجیم به نقشه

برای نمایش داده‌های بزرگ، داده را خارج از باندل JavaScript و در فایل‌های مستقل، نسخه‌دار و قابل کش نگه دارید. کلید اصلی همیشه `regionId` است.

یک رکورد متریک باید شامل `regionId`، شناسهٔ شاخص، عنوان فارسی، مقدار عددی، واحد، منبع و تاریخ مشاهده باشد. برای نمونه شاخص تولد، `metricId` می‌تواند `registered-births-1404` باشد و مقدار فقط پس از اتصال به منبع معتبر نمایش داده می‌شود.

مسیر پیشنهادی: `public/maps/iran/metrics/<metric-id>.json`. برای دادهٔ شهرستان‌ها آن را یک فایل به ازای استان نگه دارید تا با حرکت کاربر فقط همان بخش بارگذاری شود. از نام منطقه به عنوان کلید استفاده نکنید؛ نام ممکن است تکراری یا تغییرپذیر باشد.

هیچ دادهٔ ساختگی به نقشه اضافه نکنید. پنل جزئیات باید منبع، تاریخ مشاهده و واحد را هم‌زمان با مقدار نمایش دهد.

## نمونهٔ قابل دریافت

فایل `public/data-samples/iran-map-metrics.sample.json` یک نمونهٔ آموزشی قابل ورود است. مقدارهای آن واقعی نیستند و پیش از استفاده باید با داده و منبع خودتان جایگزین شوند. پس از ورود، هر `regionId` به رنگ و عدد روی همان استان یا شهرستان تبدیل می‌شود. داده‌های نامعتبر، شناسه‌های تکراری و شناسه‌های ناشناخته باید پیش از انتشار اصلاح شوند؛ هرگز آن‌ها را با نزدیک‌ترین نام منطقه جایگزین نکنید.
