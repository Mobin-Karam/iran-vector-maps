# Iran Map Studio reference

The optional `/studio` route is an adapted local reference implementation based on
[Hhhkarimi/IranMapStudio](https://github.com/Hhhkarimi/IranMapStudio), used to
evaluate and demonstrate map-editor interaction patterns. The upstream project
is MIT licensed. This project keeps the production `/map` route on its own
verified map data, package APIs, and attribution policy.

Do not treat the reference route's embedded boundary file as a replacement for
the verified production geometry in `public/maps/iran/`.
